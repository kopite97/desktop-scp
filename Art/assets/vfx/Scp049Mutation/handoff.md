## 별도 개발 PLAN의 필수 범위

1. 96×96 장식 창과 효과 수명 소유자를 만든다. 피벗(24,40)×2, `target.foot-(48,80)` 부착, 위치/드래그/발판 이동 추적, 작업 영역 밖 표시 마스크를 구현한다. 아이콘이나 입력 위치를 억지로 이동하지 않는다.
2. 전체 장식 창을 외부 프로세스까지 클릭 투과시킨다. 기존 공통 창 순서 관리자에 등록하고 독립적인 반복 최상단 요청을 추가하지 않는다.
3. 실제 Treating 시작 사건에 treat0ms를 연결한다. 예약 중에는 재생하지 않는다. 일반/과부하 치료량과 무관하게 클립120ms는 유지하고 성공/취소 사건에서 반복을 종료한다.
4. 성공 사건에서 논리 좀비 전환·ART-006 spawn·transform을 같은 시간0으로 시작한다. transform의 마지막 투명100ms를 포함해800ms 뒤 해제한다. 파일 교체만으로 이 연결이 구현됐다고 기록하지 않는다.
5. 대상 회수/삭제/만료/치료 취소 시 효과를 즉시 정리하고 실패한 치료의 transform 예약을 남기지 않는다. 재치료는 새로운 treat 프레임1에서 시작한다.
6. 봉쇄는 효과를 숨기고 시간을 동결한다. 복귀 시 유효한 대상만 같은 나이에서 이어가며 경과 시간을 따라잡지 않는다. 앱 종료는 모든 효과·창·리소스를 즉시 정리한다.
7. 프레임 번호는 JSON index0로 변환해 사용한다. Unshaded/Mix/nearest2배/중립 부모와 PNG straight alpha를 유지한다. 전체 fade를 추가하지 않고 대상 방향으로 효과를 반전하지 않는다.
