## 규격과 표현

| 항목 | 제작값 |
| --- | --- |
| 셀·표시 | 32×32 원본, nearest 1배/2배 검수. 본체 64×64와 같은 정수 배율 |
| 그림 영역 | 최대 하트 17×15 (x8,y9), 음표 15×19 (x9,y7). 나머지는 투명 여백 |
| 피벗·좌표 | (16,16), 좌상단 원점, X 오른쪽/Y 아래, 원본 픽셀 단위. 바닥 접점 없음 |
| 시점·반전 | 화면 정방향. 본체 반전에 따라 음표/하트를 뒤집지 않음 |
| 색상 | RGB/sRGB, straight RGBA PNG. 투명+6개 RGB, 프레임별 알파 |
| 레이어 | HeartFill/HeartOutline, NoteFill/NoteOutline, 숨김 Guide. 본체·배경·그림자는 없음 |
| 출력 | 256×64, 8열×2행, 고정 32×32 셀. 여백·간격·트리밍·회전·중복 병합 없음 |

- 하트: 윤곽 #512B3F, 기본 #EF7093, 그래픽 강조 #FFBFC8.
- 음표: 윤곽 #24414C, 기본 #5FCEC3, 그래픽 강조 #B2F4DF.
- 도형이 변해도 1px 외곽선을 다시 구성한다. 크기 변화는 원본 도트 단계이며 보간/안티앨리어싱 없음.
- 조명 영향 없는 작은 감정 기호다. 2색 그래픽 강조는 고정된 스타일 표현이며 동적 재질 반사가 아니다. 밤에도 기호를 읽기 위해 unlit를 요청한다.
- 노멀·반사·발광·그림자 맵을 만들지 않는다. 빛을 방출하거나 블룸을 요구하지 않는다. CanvasModulate까지 곱해지지 않도록 실제 Godot 연결에서 별도 확인한다.
- ART-002 추가 작업: 원본 r001은 유지하며 전체 PNG에 CanvasItemMaterial Unshaded/Mix를 적용한다. 중립 부모·modulate 흰색을 사용하고 본체 주야간 변조를 상속하지 않는다. PLAN-005 run-011에서 광원/CanvasModulate 4조건·16프레임의 색/알파·완전 소멸을 실제 엔진에서 확인했다. 이는 진단 경로이며 제품 스폰 시스템은 아직 없다.

## 재생 계약

| 태그 | JSON 인덱스 / Aseprite | 각 프레임 ms | 총 시간·종료 |
| --- | --- | --- | --- |
| heart | 0~7 / 1~8 | 70,80,100,160,160,120,100,60 | 850ms 일회, 완전 투명 후 제거 |
| note | 8~15 / 9~16 | 70,80,100,160,160,120,100,60 | 850ms 일회, 완전 투명 후 제거 |

- 등장 1~2, 강조 3~5, 소멸 6~8번째 프레임. 알파 160/230/255/255/230/150/80/0.
- 소멸 알파는 이미지가 소유한다. 기본 Godot modulate alpha=1, 별도 fade를 중복 적용하지 않는다.
- 시트에는 위치 상승 궤적을 굽지 않는다. 태그 한 번 재생 후 인스턴스를 제거하고 무한 반복하지 않는다.
- 생성 시 본체 JSON의 해당 프레임 reactionAnchor를 화면 좌표로 변환해 고정한다. 하트 중심 오프셋 (-14,-10), 음표 (+14,-10); 이후 이동은 Godot 소유다.
- 본체 방향을 바꾸면 연결점 좌표만 일관되게 변환하고 glyph는 정방향을 유지한다. 생성된 기호가 본체 변형을 계속 따라 떨리지 않게 한다.
- 2.6초 합성 리뷰의 생성 시점·18px 상승은 시각 예시이며 제품 생성 빈도·속도·동시 개수의 확정값이 아니다.

## 검수와 연결

- [작업 원본](source/Scp999Reaction.aseprite), [r001 제출](revisions/r001/README.md), [전달 기록](handoff.md), [검사](../../../docs/plans/evidence/ART-002/run-001/README.md).
- 실제 Scp999 r004 Godot 캡처 위에 Aseprite에서 합성해 낮/밤·밝음/어두움/무늬 배경·1배/2배를 검토했다. 효과 자체를 Godot에 연결한 증거는 아니다.
- 본체 50자세의 연결점에 효과 전체 프레임을 놓았을 때 Face 레이어와 겹친 픽셀 0. 실제 이동·물리·지연 입력 중 얼굴 겹침은 제품 검사 대상이다.
- 하트/음표 영역은 클릭 윤곽에 포함하지 않는다. 원본 본체 셀 위로 벗어나므로 PLAN-005가 창/Viewport 범위를 확보하고 투명 여백 입력 투과를 유지한다.
- 남은 항목: 사용자 시각 확인, Godot unlit/시간/창/입력/수명 통합. 엔진 비용·다중 개체·모든 DPI는 미측정이다.
