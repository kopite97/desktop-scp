## r005 현재 제출

- 사용자 지시로 ART-002에 본체 후속 수정을 포함했다. 완료된 ART-001/r004/approved_revision=4는 당시 기록으로 유지한다.
- 50프레임·10태그·64×64·3200×64 배열과 모든 시간/피벗/연결점은 r004와 같다. 새 Scp999_color.png는 외곽선을 제외한 몸체/표정이다.
- Scp999_outline.png를 Unshaded/Mix로 앞에 합성한다. lit 출력과 겹침 0, 재합성은 r004 RGBA와 정확히 일치한다. normal/specular 데이터는 r004와 동일하다.
- 중립 공통 부모, 몸체의 선택적 self_modulate, 단일 상태의 frame/FlipH/scale/visibility 동기화. 표정은 lit 유지. 원본 1px 외곽선의 색을 조명과 무관하게 보존한다.
- [r005 계약](revisions/r005/export/Scp999.contract.json), [Art 파일 검사](../../../docs/plans/evidence/ART-002/run-003/README.md), [전체 엔진 검사](../../../../docs/plans/evidence/PLAN-005/run-012/README.md).
- 최신 제출 r005 사용자 시각 확인 대기, 최근 승인 r004, 정식 제품 미적용. 아래는 이전 리비전 참조다.

## r004 이전 제출

- 두 관문 통과 후 50프레임·10태그로 확장했다. 64×64 셀, RGBA PNG 3종 3200×64·50열×1행, 패딩/트리밍 없음.
- 출력 인덱스 0~49는 r001 UI 1~50에 대응한다. 아래 전체 동작 시간표를 유지하며 피벗·reactionAnchor·trailAnchor는 [r004 계약](revisions/r004/export/Scp999.contract.json)에 있다.
- BodyColor/Outline/Face·NormalData·SpecularData 분리, 채널/알파 규약과 시험 재질 설정은 r003과 같다. 고정 몸체 명암과 Highlights는 기본색에 포함하지 않는다.
- [Art run-004](../../../docs/plans/evidence/ART-001/run-004/README.md), [PLAN-005 run-010](../../../../docs/plans/evidence/PLAN-005/run-010/README.md)에 파일·엔진 검증을 기록한다.
- 최종 사용자 시각 확인 리비전 4(2026-11-24), ART-001 completed. 정식 제품 미적용. 아래 r001/r002/r003은 제작 이력과 호환 계약의 참조다.

별도 바닥 점액 자국은 ART-003에서 제작한다. 본체에 대한 현재 사용자 확인은 r004에 기록한다.

## r003 관문 조명 계약과 r002 샘플 대응

- r003은 idle/move 총 12장의 보존된 관문 제출본이다. 원본 UI 1~12와 출력 인덱스 0~11이 순서대로 대응하며 768×64·12열×1행이다.
- idle/move는 아래 r001 시간표의 첫 두 행을 그대로 사용한다. 완전한 루프 1040ms/740ms를 제공한다. r003 레이어·기본색·채널 규약은 r002와 동일하다.
- [r003 계약 JSON](revisions/r003/export/Scp999.contract.json), [제출 명세](revisions/r003/README.md)에 검증한 Godot 연결을 기록했다.
- 채택한 진단 설정: CanvasTexture shininess .45·specular_color .35, PointLight2D 높이 100, nearest. Sprite2D.FlipH만 사용한다. 알파가 미리 곱해진 Viewport 결과는 PremultAlpha로 합성한다.
- 아래 4장 표·256×64 규격·샘플 태그는 r002 참조 기록이며 r003 재생에 사용하지 않는다.

- 방식: 동적 조명 대응. 기본색은 표시용 색, normal/specular는 수치 데이터다. 진단 임포트·색 공간·반전 확인은 PLAN-005 단계 A에 기록한다.
- 캔버스 64×64, RGB/sRGB 편집 원본. 출력 3종 모두 RGBA PNG 256×64, 4열×1행, 여백/간격/트리밍/회전/중복 병합 없음. 정수 배율·nearest·반복 끄기를 시험 기준으로 한다.
- 기본색 몸체 #F78A21D3, r001 Body의 방향성 명암과 Highlights는 제거했다. Outline·Face는 픽셀 그대로 보존했다. 눈의 작은 밝은 점은 표정 그래픽이다.
- 표시 레이어: BodyColor·Outline·Face. 숨김 데이터/참조: NormalData·SpecularData·ReferenceR001. 데이터 레이어를 기본색에 합성하지 않는다.
- normal: 실루엣 거리 기반 높이장에 평활화를 적용한 기울기. RGB는 X 오른쪽/Y 위/Z 관찰자 방향을 0~255로 인코딩한다. 바깥쪽 (128,128,255), 전체 alpha=255. r002 제출 당시 미검증이었던 팔·꼬리의 방향과 광택은 이후 PLAN-005 run-004/007/010에서 확인했다.
- specular: RGB 동일 회색값으로 몸체 180, 표정/윤곽/바깥 0, 전체 alpha=255. CanvasTexture specular/shininess 입력 후보이며 재질 파라미터와 실제 반응은 시험 후 확정한다. 투명도 마스크가 아니다.
- 커버리지와 몸체 반투명은 기본색 alpha만 소유한다. 데이터 맵은 표시색 팔레트로 양자화/색 보정하지 않는다. 경계 패딩·필터 결과는 실제 엔진에서 확인한다.
- 원본 팔레트 6칸은 편집 편의용이며 사용 색 전체 목록이나 normal 색 제한이 아니다.
- 좌우 반전은 색 위치와 법선 방향을 함께 검증한다. 엔진의 기본 벡터 처리를 확인하기 전 수동 채널 반전을 추가하지 않는다.
- 피벗 (32,56)은 모든 샘플 동일하다. 효과 연결점은 r001 계약을 참조하되 이번 샘플은 효과 통합용이 아니다.

| 샘플 UI / 출력 인덱스 | 원본 r001 UI / 인덱스 | 원본 태그 | 유지한 ms |
| --- | --- | --- | --- |
| 1 / 0 | 1 / 0 | idle | 220 |
| 2 / 1 | 7 / 6 | move | 120 |
| 3 / 2 | 9 / 8 | move | 100 |
| 4 / 3 | 12 / 11 | move | 160 |

샘플 태그는 idle_sample(UI 1), move_key_samples(UI 2~4, 1회)다.
샘플 시간은 선택된 원본 프레임의 시간이며 빠진 프레임 시간을 대체하지 않는다. 완전한 idle/move 루프가 아니다.
시트·좌표·시간·맵 계약은 [r002 JSON](revisions/r002/export/Scp999.contract.json)에 제공한다.
기본색만 보았을 때 평평한 모습은 고정 명암 제거 결과다. 최종 입체감·젤리 재질 품질을 판정한 상태가 아니다.

## r001 전체 동작과 시간

| 태그 | Aseprite 프레임(1부터) | 출력 인덱스(0부터) | 프레임별 ms | 재생 |
| --- | --- | --- | --- | --- |
| idle | 1–6 | 0–5 | 220, 180, 100, 160, 180, 200 | 반복 |
| move | 7–12 | 6–11 | 120, 120, 100, 100, 140, 160 | 반복 |
| typing_react | 13–19 | 12–18 | 90, 80, 100, 90, 90, 110, 140 | 일회 |
| pet | 20–25 | 19–24 | 130, 140, 140, 140, 130, 140 | 반복 |
| pet_recover | 26–28 | 25–27 | 100, 110, 170 | 일회 |
| takeoff | 29–32 | 28–31 | 90, 110, 70, 80 | 일회 |
| fall | 33–36 | 32–35 | 140, 140, 140, 140 | 반복 |
| land | 37–41 | 36–40 | 60, 80, 100, 100, 160 | 일회 |
| balance | 42–47 | 41–46 | 120, 140, 120, 140, 120, 150 | 반복 |
| balance_recover | 48–50 | 47–49 | 100, 120, 160 | 일회 |

- move: 총 740ms, 모든 프레임 그림 하단은 y=55(픽셀 끝 y=56). 수직 이동 없이 꼬리 길이·앞쪽 기울기 변화로 끌림 표현.
- typing_react: 셀 안에서 최대 6px 위로 튀는 연출이 포함된다. 같은 움직임을 Godot의 위치 점프로 중복 적용하지 않는다.
- pet: 요청 중 반복, 해제하면 pet_recover로 회복. 실제 입력 우선순위·회복 전환 타이밍은 개발 담당.
- takeoff: 마지막 프레임을 물리 이륙 신호에 대응하는 후보로 제공. 실제 낙하 위치는 Godot가 제어한다.
- fall은 반복/유지, 접지 시 land로 전환한다. land 종료 후 idle/move.
- balance는 좌우 흔들림, 안정 시 balance_recover→idle/move.
- 태그 간 모든 조합을 자동으로 부드럽게 잇는 전환 시스템은 제작하지 않았다. 개발 시 실제 상태 전환으로 검증한다.

- 50프레임의 원본/PNG 픽셀 일치, 경계 윤곽, 반투명, 캔버스 안 수용 검사 통과.

- 사용자 시각 확인: r001의 형태 의견 이후 r004 결과를 제시했고, 2026-11-24 “Art-001은 괜찮아 보여” 확인을 r004 피드백 F-006에 기록했다.
- 진단 씬 조명·반전·재생·본체/빈 공간/숨김 입력 확인. 제품 상태·물리·실제 시간대 연동은 미실행.
