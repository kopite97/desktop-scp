## 별도 개발 PLAN에 포함할 항목

1. 기존 임시 손·발 렌더링 및 손 입력 영역을 제거하고 두 발 시트를 합성한다. alpha>0 아이콘 경계와 하단 지지 열을 캐시해 부착한다. 셀 전체를 클릭 영역으로 만들지 않는다.
2. 게임 상태에서 spawn/idle/move/fall/land를 고른다. 치료 성공 사건에서 논리 좀비 전환·ART-006 spawn·ART-007 transform을 동시에 시작한다. spawn 동안 세계 이동은 계속된다.
3. spawn/land는 공중·드래그·회수/삭제에 즉시 양보한다. 드래그 중은 fall 자세를 사용하고 실제 착지가 발생했을 때만 land를 시작한다. 방향 변경은 클립 시간을 초기화하지 않는다.
4. 회수/만료 시 보상·예약·입력·생존 수 등 게임 상태는 즉시 한 번만 정리한다. collect360ms/expire660ms는 별도의 비상호작용 표시 객체에서만 재생한다.
5. 소멸 객체는 마지막 아이콘 이미지의 읽기 전용 캐시 참조, 위치, 방향, 마지막 발 자세를 확보한다. 최초 순간의 자세 전환을 확인하고 태그를0초에서 시작한다. 새 게임 객체로 등록하거나 중복 회수하지 않는다.
6. JSON의 bodyAlpha는 아이콘만 변조한다. 발 알파는 PNG에 구워져 있다. 마지막 완전 투명 프레임 시간까지 포함한 수명 뒤 아이콘 캐시 참조·창·텍스처를 정확히 한 번 해제한다.
7. 봉쇄 시 살아 있는 표시 객체를 숨기고 시간을 동결한다. 복귀 시 남은 시간부터 이어가며 경과 시간을 따라잡지 않는다. 앱 종료는 재생 종료를 기다리지 않고 즉시 정리한다.
8. 공통 창 순서 관리자와 기존 겹침 드래그 수정을 유지한다. 소멸 창은 외부 프로세스까지 완전 클릭 투과해야 하며 별도 반복 최상단 요청을 만들지 않는다.

## 통합 인수 검사

- 여섯 형태·양방향·8개 겹침의 정렬/로고 불변/발 경계/투명 구멍을 실제 제품에서 확인한다. 폭1/2와 비대칭 하단 지지점도 추가해 극단 입력에 대한 분기와 좌우 슬롯 겹침을 검사한다.
- 이동·낙하·드래그·착지·치료 성공 도중 전환, 방향 변경 시 위상 보존, collect/expire 반복 클릭·새 스폰·봉쇄/복귀·종료를 확인한다.
- alpha16 윤곽과 독립 외부 수신기로 클릭 투과를 확인한다. 같은 창 수에서 비용과 캐시/창 정리를 기록한다.
- Unshaded/Mix/nearest2배/중립 부모의 색·알파 불변을 검증한다. 동적 조명 노멀·반사 맵은 이 제출에 없다.
