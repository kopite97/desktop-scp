## 레퍼런스 반영

- [나란히 비교](revisions/r001/review/reference-comparison.png): 가면 능선과 깊은 눈구멍, 후드의 안쪽 그늘, 겹친 망토와 큰 세로 주름, 가죽 가방의 금속 잠금쇠, 장갑·수술 도구를 반영했다.
- 작은 균열·불규칙한 봉제선·재질 노이즈는 픽셀 가독성을 위해 생략했다. 천은 푸른 회색, 가죽은 따뜻한 회갈색 명암으로 구분한다.
- 참조의 성인에 가까운 체형을 짧은 SD 체형으로 조정했다. 소품은 프레임 간 같은 역할과 위치 관계를 유지한다.
- 치료 때 가방을 낮추고 팔을 뻗으며, 메스와 주사기를 번갈아 쓴다. 치료 대상·혈흔·변이 효과는 본체 스프라이트에 그리지 않는다.

## 조명·재질 계약

- 전체 본체·외곽선·소품을 Unshaded/Mix, 중립 부모, modulate 흰색으로 표시하는 계약을 채택했다. 깊은 로브의 작은 명암 구분과 부리 가독성을 일정하게 유지하기 위해 동적 조명보다 고정 명암을 선택했다.
- `Scp049.png`는 고정 명암을 포함한 표시용 straight RGBA다. 노멀·반사·발광·독립 그림자 맵은 이 계약에 필요하지 않아 제작하지 않았다.
- 조명 방식 후보였던 Unshaded를 ART 실행 범위에서 확정했다. 이를 동적 조명 대응 리소스로 전달하지 않는다.
- 밝음/어두움/무늬 배경의 원본 픽셀 비교는 검수했다. Godot의 실제 Light2D/CanvasModulate/부모색 영향·입력 윤곽·성능은 별도 적용 PLAN에서 확인해야 하며 이번 ART에서 검증 완료로 기록하지 않는다.

## 동작·시간

아래 범위는 Aseprite 1부터 시작한다. 전달 contract의 from/to와 index는 0부터 시작한다. 시간 단위 ms.

| 태그 | 프레임 | 시간 | 반복·종료 |
| --- | --- | --- | --- |
| idle | 1–4 | 300,160,300,160 | 반복, 호흡과 소매의 작은 변화 |
| move | 5–12 | 100,80,100,120,100,80,100,120 | 반복, 발 교대·로브·가방 흔들림 |
| treat_start | 13–16 | 140,120,140,180 | 일회 → treat_loop |
| treat_loop | 17–22 | 160,120,180,160,120,180 | 반복, 치료 시간 3초는 게임이 소유 |
| treat_end | 23–26 | 130,130,160,180 | 일회 → idle/이동 |
| takeoff | 27–29 | 100,80,120 | 일회 → fall |
| fall | 30–32 | 140,120,140 | 반복, 실제 착지 시 land |
| land | 33–35 | 100,130,170 | 일회 → idle/이동 |
| balance | 36–39 | 140,180,140,180 | 반복 → balance_recover |
| balance_recover | 40–42 | 120,140,180 | 일회 → idle/이동 |

- 42프레임 중 33개의 고유 합성 모습이며 정지 유지·복귀 자세의 중복은 의도적이다. 시트에는 모든 프레임을 보존한다.
- 취소/낙하/드래그는 치료 태그 종료를 기다리지 않고 현재 제품 상태로 전환한다. 이동을 프레임에 굽지 않는다.
- 치료 접점은 contract의 프레임별 treatmentAnchor, 도구는 tool 필드다. 반전 접점은 `x = 64 - x`, y 유지. 피벗은 (32,56) 유지, 가방과 도구도 같이 반전한다.
- 캐릭터 소멸 태그는 범위 밖이므로 투명 종료 프레임을 추가하지 않는다. 숨김·종료는 제품이 관리한다.
