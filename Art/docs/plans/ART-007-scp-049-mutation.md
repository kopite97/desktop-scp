# ART-007 SCP-049 치료와 변이 오라

## 목표와 범위

- AssetId Scp049Mutation, vfx. 48×48 셀, 피벗(24,40), 대상 중심의 보라색/초록색 오라. 투명 배경, 별도 장식 효과이며 본체/파일 그림이나 클릭 영역은 포함하지 않음.
- 2026-11-24 별도 아트 후보로 생성. 2026-11-25 순차 제작 승인과 선행 ART-006 r001 시각 확인 완료에 따라 실행한다.
- 포함: Aseprite 원본·PNG 시트·프레임 JSON/계약·배경/재생 리뷰·handoff. 제외: 게임 규칙/물리/입력/실제 파일 작업.
- r001 제작·시각 승인 완료. PLAN-006 임시 도형 표현과 별개이며 제품 정식 적용은 후속 개발 범위다.
- 2026-11-25 [아이콘 복제 기획](../../../docs/game-design/desktop-icon-clones.md)과 [PLAN-012](../../../docs/plans/PLAN-012-desktop-icon-clones.md)에 맞춰 임의 아이콘에 공통 적용하는 효과로 유지한다. 아이콘별 효과를 따로 그리지 않는다.

## 기준 문서와 선행 조건

- [기획 원본](../../../SCP_site-desktop.md) 2·3절, [PLAN-006](../../../docs/plans/PLAN-006-scp-049.md), 요청 PLAN-006-SPR-004.
- [Art 작업 절차](../agents/workflow.md), [리비전](../agents/revisions.md), [애니메이션](../agents/animation.md), [조명](../agents/lighting.md), [전달](../agents/handoff.md).
- [아이콘 좀비 연결 계약](../../../docs/game-design/icon-zombie-presentation.md)을 크기·좌표·시간·취소 조건의 원본으로 사용한다. ART-006은 발만 제작하며 효과에는 발·몸체·049 도구를 중복해서 그리지 않는다.
- treat: 실제 Treating 구간 반복. 일반 치료3초·과부하 약2초 모두 게임 완료/취소 사건을 따른다. 효과 자체의 루프 속도는 유지하고 고정3초 완성 영상은 만들지 않는다.
- transform: 논리 변이 성공 즉시 ART-006 발 등장과 함께0초 시작, 완전 투명 마지막 프레임을 포함해 총800ms 일회. 효과가 끝날 때까지 좀비 전환을 늦추지 않는다.
- 합성: 원본48×48/피벗(24,40), nearest2배의 별도96×96 장식 창.64×64 아이콘 창에 잘라 넣지 않는다. 대상 foot에 부착하고 대상 이동/발판/드래그를 따라간다.
- 한 시트로 몸체보다 앞에 표시하되 로고 중심은 투명하게 비우고 가장자리의 가는 오라/작은 입자로 표현한다. 기본색·로고의 식별성을 유지하며 불투명 덮개·화면 섬광은 제외한다.
- 치료 취소/대상 삭제/회수/만료 시 관련 효과를 즉시 정리한다. 봉쇄는 숨김·시간 정지, 복귀는 유효한 대상만 같은 나이로 이어서 재생한다. 앱 종료는 즉시 해제한다. 전체 효과는 클릭 투과다.
- 후속 개발 PLAN에는96×96 효과 창·알파/부착 좌표·공통 창 순서 등록·게임 시간과 이벤트 연결·수명/정리를 포함한다. PNG 교체만으로 구현된다고 간주하지 않는다.
- RGBA/sRGB, 고정 셀/원본1배 PNG, nearest2배 제품 표시. trim/rotation/padding/중복병합 없이 프레임별 ms·pivot·상태 접점·반전 계약을 명시한다.
- 조명 계약: Unshaded/Mix/중립 부모, 고정 명암과 알파를 유지. 049 세트의 작은 형태/색 대비가 우선이며 동적 노멀/반사 맵은 현재 범위에 포함하지 않는다. 대표 샘플에서 가독성을 확인한다.
- 정지/이동 또는 등장/소멸 대표 샘플을1배/2배·밝음/어두움/무늬 배경에서 먼저 검수한 뒤 전체로 확장한다. Godot 통합 검증은 별도 개발 계획에서 담당한다.
