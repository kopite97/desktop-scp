# ART-004 SCP-049 본체와 치료 동작

## 목표와 범위

- AssetId Scp049, characters. 64×64 셀, 피벗(32,56), 검은 망토/하얀 새 부리 가면의2등신 SD. 1px 어두운 윤곽과 밝은 배경에서도 보이는 내부 대비. 가방/메스/주사기를 사용하는 엄숙한 수술 동작.
- 2026-11-24 사용자 PLAN-006 실행 시 별도 ART 후보로 작성했으며, 사용자의 “Art-004를 시작해줘.” 지시로 이 ART의 제작 실행을 승인받았다.
- 포함: Aseprite 원본·PNG 시트·프레임 JSON/계약·배경/재생 리뷰·handoff. 제외: 게임 규칙/물리/입력/실제 파일 작업.
- r001 원본·출력·검수 자료 제작 및 사용자 시각 확인 완료. PLAN-006 도형 임시 표현과 제품 적용은 별도다.

## 기준 문서와 선행 조건

- [기획 원본](../../../SCP_site-desktop.md) 2·3절, [PLAN-006](../../../docs/plans/PLAN-006-scp-049.md), 요청 PLAN-006-SPR-001.
- [Art 작업 절차](../agents/workflow.md), [리비전](../agents/revisions.md), [애니메이션](../agents/animation.md), [조명](../agents/lighting.md), [전달](../agents/handoff.md).
- 태그 후보: idle, move, treat_start, treat_loop, treat_end, takeoff, fall, land, balance, balance_recover. 대기/보행 반복, 치료 시작/종료 일회·치료 반복은 게임 치료3초에 맞춰 연장. 실패/취소 시 즉시 이동/공중 상태로 전환 가능. 좌우 반전 및 반전한 수술 접점 명시.
- RGBA/sRGB, 고정 셀/원본1배 PNG, nearest2배 제품 표시. trim/rotation/padding/중복병합 없이 프레임별 ms·pivot·상태 접점·반전 계약을 명시한다.
- 조명 확정: Unshaded/Mix/중립 부모, 고정 명암과 알파를 유지. 049 세트의 작은 형태/색 대비가 우선이며 동적 노멀/반사 맵은 현재 범위에 포함하지 않는다.
- 정지/이동 또는 등장/소멸 대표 샘플을1배/2배·밝음/어두움/무늬 배경에서 먼저 검수한 뒤 전체로 확장한다. Godot 통합 검증은 별도 개발 계획에서 담당한다.

## 필수 제작 레퍼런스

- 2026-11-24 사용자 “Art플랜에도 이 래퍼런스를 참고하는 것을 명시해줘” 요청에 따라 [ref-001 상세 컨셉 시트](references/ART-004-scp-049-character/ART-004-scp-049-character-ref-001-detail-reference.png)를 본체·치료 동작 제작 시 반드시 확인하고 참고한다.
- 외형에 반영할 방향: 밝은 가면의 능선과 깊은 눈구멍, 얼굴을 감싸는 후드, 겹쳐진 어깨 망토와 굵은 주름, 장갑·가방의 가죽과 천의 재질 차이, 엄숙한 자세와 수술 소품의 구조.
- 정면 3/4·측면·후면을 함께 대조해 방향과 애니메이션이 바뀌어도 가면·망토·가방의 구조가 이어지도록 한다. 소품 위치와 좌우 반전 처리는 실제 동작 계약에 기록한다.
- 픽셀화 시 작은 균열·봉제선·재질 노이즈를 단순화하되 큰 형태와 명암 구분을 유지한다. 기존 SD 비율·1px 윤곽·실제 표시 크기 가독성을 기준으로 조정하며, 참고 시트 자체의 해상도를 셀 규격으로 간주하지 않는다.
- 대표 정지·보행·치료 샘플 검수에서 레퍼런스와 나란히 비교하고 반영한 특징·단순화한 특징·차이의 이유를 기록한다. 참고 지정은 최종 스프라이트의 시각 승인과 구분한다.
- 출처·생성 프롬프트·활용 기록은 [참고 폴더 README](references/ART-004-scp-049-character/README.md)를 따른다.

## 완료 기준과 검증 방법

- 원본/제출/PNG·JSON 픽셀/시간/태그가 일치하고 반복 경계가 의도대로 동작한다. 본체 소멸 태그는 범위 밖이며 숨김은 제품이 소유한다.
- 실제1배/2배·세 배경·반전/겹침 재생에서 실루엣·가독성·클리핑을 검수한다.
- 대표 샘플과 ref-001의 비교 기록으로 가면·망토·소품의 세부 표현 반영과 픽셀화에 따른 단순화 이유를 확인한다.
- 현재 리비전의 사용자 시각 확인을 기록한다. 기술 검사나 계획 실행 승인을 시각 승인으로 대신하지 않는다.
- Unshaded·알파·색 불변성/제품 입력/성능은 Godot 적용 담당과 전달 계약에서 구분한다.

- run-001: 64×64, 42프레임·10태그·8레이어. 작업 원본/제출 보존본/PNG의 합성 픽셀과 태그·시간·좌표 일치, 알파 오류0·외곽선 경계 오류0·캔버스 잘림0. 치료 도구 접점의 불투명 픽셀 확인 PASS.
- 밝음·어두움·무늬 배경, 1배/2배·반전·겹침·레퍼런스 비교 자료를 확인했다. LG 모니터의 Aseprite GUI에서 42프레임 진행 로그와 실제 재생 상태를 확인했다. 전체 타임라인 리뷰는 제품의 상태 전환·치료 3초 제어 검증을 대신하지 않는다.
- 사용자 r001 시각 확인 완료. Godot 적용·조명 불변성·입력·성능은 미확인이며 별도 제품 통합 범위다.
