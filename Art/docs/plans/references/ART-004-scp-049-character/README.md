# ART-004 SCP-049 참고 이미지

- 대상: [ART-004 SCP-049 본체와 치료 동작](../../ART-004-scp-049-character.md).
- 2026-11-24 사용자 요청으로 역병의사의 세부 표현을 위한 참고 이미지 저장 공간을 마련했다.
- 2026-11-24 사용자 요청으로 이미지 검색 후 내장 image_gen으로 상세 컨셉 시트 1장을 생성했으며, 이후 사용자가 ART-004 제작 시 참고하도록 지정했다. 최종 스프라이트·해상도 변경·시각 승인은 별도다.
- 저장·명명·원본 보존은 [PLAN별 참고 이미지 규칙](../../../agents/project-structure.md)을 따른다.
- 검색 출처·접근 한계·도구·전체 생성 프롬프트: [ref-001 생성 기록](ref-001-generation.md).

## 제작에 반영할 기준

- 반영 기준의 원본은 [ART-004의 필수 제작 레퍼런스](../../ART-004-scp-049-character.md)다. 가면·후드·망토·재질·소품을 참고하고 대표 샘플에서 반영 결과를 비교한다.
- 단순화 대상: 작은 균열·봉제선·재질 노이즈는 실제 픽셀 크기에서 읽히는 만큼만 남긴다. 이 참고 시트의 전체 해상도를 스프라이트 셀 규격으로 사용하지 않는다.
- 우선 기준: 사용자 피드백과 ART의 확정된 SD·윤곽·가독성 기준을 우선한다. 생성 이미지의 비율·소품 위치를 그대로 확정하지 않는다.
- 연결된 [Scp049 에셋 명세](../../../../assets/characters/Scp049/spec.md)에 r001 반영·단순화 항목과 비교 이미지를 기록했다.
