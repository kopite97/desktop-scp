# 애니메이션과 정렬

적용: 방향·상태·프레임·시간. 탐색: [디자인](design.md), [전달](handoff.md).

## 동작 계약

- 승인된 PLAN의 실제 상태와 필요한 표현을 연결한다. 예시 idle·move·pet 등을 구현된 상태로 기록하지 않는다.
- 태그명, 방향, 프레임 범위, 각 프레임 시간(ms), 반복/일회/왕복, 종료 후 자세를 명세에 적는다.
- 전체 공통 FPS나 프레임 수를 임의로 정하지 않는다. 불균일 시간을 평균 FPS 하나로 대체하지 않는다.
- Aseprite 도구의 프레임/태그 인덱스는 1부터 시작한다. Godot 연결 시 실제 데이터의 인덱스 규약을 확인해 명시적으로 변환한다.
- 정적 변형을 프레임으로 관리하면 애니메이션이 아닌 변형 선택임을 표시한다.

## 정렬과 형태

- 세트 내 캔버스·바닥 접점·피벗 기준을 공유한다.
- 눌림·출렁임·점프 같은 의도적 변형과 프레임 실수로 생긴 부피 변화·위치 흔들림을 구분한다.
- 비대칭 외형·광원을 확인한 후 좌우 반전 재사용 여부를 정한다.
- 몸체·그림자·효과를 분리하면 공통 좌표와 재생·합성 관계를 적는다.
- 동작 중 가장 크게 뻗는 프레임까지 여백·창 경계에 잘리지 않는지 확인한다.
- 조명용 맵의 프레임·태그·시간·피벗·변형 대응과 좌우 반전은 [조명 지침](lighting.md)을 따른다. 늘어진 몸체에 정지 노멀맵을 그대로 재사용해도 되는지 실제 재생으로 확인한다.

## 재생 검수

- 정지 프레임 접촉표와 실제 시간 재생을 모두 본다.
- 반복의 마지막→첫 프레임, 상태 전환, 정지·복원 시 모습을 확인한다.
- Aseprite에서 재생 확인한 범위와 Godot에서 이동 속도·입력 상태와 연결해 확인한 범위를 구분한다.
- 스프라이트 변경 후 입력 윤곽이 몸체를 따라가는지는 제품 검증이다. 기존 임시 다각형에 맞춰 그림을 왜곡하지 않는다.
