# 아트 양식 MAP

| 작성 대상 | 양식 |
| --- | --- |
| 에셋 규격·제작 ART 연결 | [asset-spec](asset-spec.md) |
| 제출 시점 명세·원본·출력·검수 | [revision](revision.md) |
| 제품 요청·수령·Godot 적용 | [handoff](handoff.md) |
| 아트 제작 계획 ART | [Art PLAN 템플릿](../docs/plans/_template.md) |

ART는 Art PLAN 템플릿을 Art/docs/plans에 복사해 ART-NNN-topic.md, type: art, status: proposed로 작성한다.
승인·상태·리비전 규칙은 [Art PLAN 관리](../docs/plans/plan.md)를 따른다.
에셋 작업의 결과물 위치·완료 기준에는 아래 양식의 규격·리비전·검수 기록을 연결한다.
양식 복사 후 링크는 실제 저장 위치를 기준으로 갱신한다. 미생성 파일은 예정 경로로 적는다.
