# TECH-006 동적 조명을 고려한 아트 제작과 샘플 검증

- 근거: 2026-11-23 사용자가 고정 명암과 후속 조명 준비의 누락을 지적하고 앞으로 반영할 지침 수정을 요청했다.
- 적용 원본: [Art 조명 지침](../../Art/docs/agents/lighting.md).
- 관계: [TECH-005](TECH-005-separate-art-plans.md)의 Art/개발 책임 분리를 보완한다. 아트 세부 지침은 Art 내부에 유지한다.
- 채택 범위는 제작·전달·검증 절차다. 특정 셰이더·조명 수치·새 PLAN 실행을 승인한 기록이 아니다.

## 문제와 제약

Scp999 r001의 Body 명암과 Highlights가 출력에 합쳐져 있다.
기존 계획은 동적 조명을 후속 미정으로 두어 기본색/보조 맵 준비와 엔진 시험을 구체적인 선행 조건으로 연결하지 못했다.
50프레임 전체 보조 맵을 먼저 만들면 반투명·변형·반전·픽셀 표현이 맞지 않을 때 수정 비용이 커진다.

## 결정

- 제작 전 에셋의 조명 방식과 원본에 고정할 표현·엔진에서 계산할 표현을 명시한다.
- 동적 조명용 기본색의 강한 방향성 명암을 분리하고, 맵의 역할·프레임/좌표·채널·색 공간·반전 계약을 기록한다.
- 대표 정지/이동 샘플로 품질·성능을 확인한 뒤 전체 프레임으로 확장한다.
- 조명용 리소스가 범위이면 엔진 샘플 검증을 완료 조건에 포함한다. 전체 게임 기능의 완료와 구분한다.
- 조명 영향 없는 UI/VFX는 예외 사유와 합성 검증을 남긴다. 모든 에셋에 보조 맵을 강제하지 않는다.
- Art는 이미지·맵·검수, 개발은 광원·시간·창/입력·실행 검증을 담당한다. 서로의 PLAN·제출 리비전·증거를 연결한다.
- 형태 승인과 재질/조명 승인, 파일 준비와 제품 적용을 따로 기록한다.
- 로컬 시간·주광원/주변 밝기·접지 그림자는 시험 계약을 정의한다. 구체 구현과 제품 수치는 해당 PLAN에서 확정한다.

## 대안과 선택 이유

- 현재 PNG에 동적 광원만 추가: 고정 명암·반사와 엔진 빛이 충돌할 수 있어 기준안으로 채택하지 않는다.
- 모든 프레임의 모든 맵 즉시 제작: 필요성과 엔진 결과를 확인하기 전 반복 작업이 커지므로 샘플 검증을 먼저 한다.
- 아트 지침을 루트 docs/agents에 복제: 사용자의 Art 내부 관리 원칙에 따라 링크만 둔다.

## 영향과 검증

- Art MAP·디자인·작업 절차·애니메이션·전달·검증·계획 관리 및 양식에 연결한다.
- ART-001은 active·r001 시각 확인 대기를 유지하고 조명 준비 미완료를 명시한다. r001 파일·기존 증거는 보존한다.
- ART-002/003·PLAN-005의 기존 제외 문구는 조명 방식·샘플 검증 의무와 모순되지 않게 보완한다.
- 새 PLAN 활성화·아트 수정·Godot 코드 구현은 수행하지 않는다.
- 문서 검사기에 조명 지침을 필수 문서로 등록하고 기존 회귀 테스트와 문서 검사를 실행한다.
- 실제 결과: 회귀 테스트 21개 및 문서 검사 통과. [변경·검증 기록](../../Art/docs/evidence/lighting-guidance-2026-11-23/README.md).
