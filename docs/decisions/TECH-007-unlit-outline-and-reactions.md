# TECH-007 본체 외곽선과 반응 효과의 조명 제외

- 근거: 사용자가 조명 제외 지침 보완과 PLAN 반영, 완료된 ART-001의 본체 후속 수정을 ART-002에 묶어 실행하도록 지시했다.
- [TECH-006](TECH-006-lighting-aware-art.md)의 샘플 우선 검증과 Art/개발 분담을 보완한다. [Art 조명 지침](../../Art/docs/agents/lighting.md)이 세부 규칙의 원본이다.
- [ART-002](../../Art/docs/plans/ART-002-scp-999-reaction.md)는 반응 효과 Scp999Reaction r001과 본체 Scp999 r005를 각각 추적한다. 완료된 ART-001/r004/승인4를 변경하지 않는다.

## 문제와 제약

- 합쳐진 기본색 PNG의 외곽선은 몸체와 함께 조명 계산을 받아 색이 변한다. 기호 전체 제외와 외곽선만 제외를 구분해야 한다.
- 승인본 보존·1px 굵기·원래 알파·프레임 동기화가 필요하다. 별도 노드의 추가 비용과 부모 색 변조도 확인해야 한다.

## 결정

- 몸체/표정은 동적 조명, 원래 1px 외곽선은 별도 RGBA PNG와 Unshaded Sprite2D로 합성한다. 두 출력의 커버리지는 겹치지 않으며 원래 합성 픽셀을 재구성한다.
- 프레임·피벗·배율·FlipH·가시성은 같은 상태 소유자가 갱신한다. 표정을 unlit로 바꾸거나 윤곽을 두껍게 다시 그리는 변경은 포함하지 않는다.
- 하트/음표는 전체 PNG Unshaded, 원본 알파 소멸 유지. 부모 색 변조를 상속하지 않으며 원본 PNG에 Mix, 투명 Viewport 출력에 PremultAlpha를 사용한다.

## 대안과 선택 이유

- 외곽선을 합친 단일 lit 텍스처는 조명에 따라 선 색이 변한다. 색 범위로 외곽선을 추측하는 셰이더는 표정/몸체와 혼동할 수 있어 채택하지 않는다.
- 별도 출력/노드는 재생 동기화와 추가 그리기 비용이 생긴다. 4장 관문 후 전체 프레임·비용을 실제 엔진에서 확인한다. Unshaded가 부모 modulate를 취소한다고 가정하지 않는다.

## 영향과 검증

- [PLAN-005](../plans/PLAN-005-scp-999.md) 단계 A의 진단에서 적용한다. 정식 제품 상태/스폰/입력 시스템 구현 완료를 뜻하지 않는다.
- r004·효과 r001 원본을 보존하며 본체 r005의 사용자 최종 시각 승인은 별도다.
- 1배/2배·광원 방향·낮/밤·반전·주변색·재생 동기화·알파·비용의 실제 결과는 해당 PLAN의 새 run에 기록한다.
