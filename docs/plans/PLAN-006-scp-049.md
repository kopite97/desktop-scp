- 작업 기록: `docs/plans/PLAN-006-scp-049.md` 갱신.
- 검증 색인: `docs/plans/evidence/PLAN-006/run-001/README.md`.
- 검증 결과: `docs/plans/evidence/PLAN-006/run-001/results.json`.

- 검증 회차는 run-001부터 증가시키며 기존 증거를 덮어쓰지 않는다. 선택 자료가 미생성인 경우 이유를 기록한다.
