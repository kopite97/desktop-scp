# PLAN-005 run-006 — 실제 창과 입력 확인

- r003, 주 모니터 usable origin에 맞춰 실험 창·두 투명 창을 배치했다. [로그](execution.log), [창 상태](windows.json).
- computer-use/sky로 실제 Windows 창을 조작했다. 진단 창을 앞으로 가져와 두 개체의 동일 조명·동작 표시를 확인하고 Space로 정지했다.
- 본체 창 로컬 (64,80) 클릭 → LIGHTING_BODY_CLICK 1.
- 뒤쪽 실험 창 좌표 (110,430), 개체 창의 투명 모서리 클릭 → LIGHTING_BACKGROUND_CLICK 1, 본체 카운터 변화 없음.
- H로 두 개체 숨김 후 이전 몸체 위치 (164,500) 클릭 → LIGHTING_BACKGROUND_CLICK 2. H로 복원하여 두 창 표시 확인.
- 위 입력 수신은 별도 native 창 뒤의 진단 배경이 받은 실제 이벤트다. 다른 사용자 앱의 내용/입력을 수집하지 않았다. 같은 프로세스의 독립 창 시험이며 임의 외부 앱과의 모든 조합을 보장하지 않는다.
- 첫 프레임 타이밍 수정 전 빌드이므로 최종 재생 수치는 run-007을 사용한다. 결과 숫자를 소급 변경하지 않았다.
