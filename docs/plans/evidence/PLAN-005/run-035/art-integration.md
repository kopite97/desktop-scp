# SCP-999 최종 제품 적용 계약

- 이전 [수령 계약](../run-025/art-integration.md)의 파일/태그/배율/알파/시간/상한을 유지한다. [SHA256 재검사](../run-037/asset-hashes.json): Scp999 r005·Reaction r001 승인본, Trail r001 미승인 임시본10개 모두 원본 및 이전 실행과 동일.
- 색은 PNG 수정 없이 주변광 .42→.9, 주광 에너지 .72→.5, 광원색 (1,.95,.88)→(1,.98,.94)로 밝힌다. idle 동일 프레임의 렌더 몸체 평균 밝기 +41.21%, 알파/외곽선 오류0. [비교](../run-029/README.md). 전체 프레임 RGB 행렬 재측정은 아니다.
- Scp999State의 Position/Foot는 공통 PlatformWorld에서 파생한다. 접점 (32,56)×2, 보수적 충돌 폭128px·높이112px으로 최대 자세의 여백을 포함한다. 이동 속도는160 물리px/s다.
- takeoff/fall/land/balance/balance_recover는 실제 물리에서 전환한다. land와 balance_recover는 각 계약 시간이 끝나기 전에 idle로 덮어쓰지 않는다. 그림의 튀는 모션은 추가 중력으로 적용하지 않는다.
- 오른쪽 드래그 해제는 낙하 후 실제 충돌에서 착지한다. 숨기는 동안 드래그를 취소해 현재 공중 위치를 보존하고 복원 후 중력을 계속한다. 바닥 스냅 정책은 대체되었다.
- 공중/균형은 pet·typing보다 우선한다. 쓰다듬는 도중 발판이 없어지면 즉시 pet을 중단한다. 커서 추적은 같은 물리 Walk/자동 인접 도약을 사용한다.
- 점액은 생성 지지면 ID·원점을 저장한다. 같은 지지 창의 이동만 반영하며 본체 이동에는 끌려가지 않는다. 가림·최소화·종료·200px 초과 지지 순간이동이면 제거, 바닥은 고정. 생성/수명/상한은 기존300ms+48px/2700ms/12개다.
- native 표시 갱신은 몸체를 올린 뒤 점액을 뒤에, 하트/음표를 위에 둔다. 장식의 layered/transparent 클릭 투과는 유지한다.
- LG의 실제 창/소유 별도 입력 수신기로 [105개 검사](results.json) 통과. [후속 규칙 검사](../run-037/results.json)66개. ART-003 시각 승인으로 해석하지 않는다.
