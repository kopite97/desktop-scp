# PLAN-011 수정 후 LG 미리보기

- 명령: `./scripts/godot.ps1 -Action Run -MonitorId GSM5BDE -LogFile docs/plans/evidence/PLAN-011/run-010/live-preview.log`.
- 사용자에게 보이는 LG 화면에서 SCP-999·SCP-049·데이터를 실행한다. [로그](live-preview.log)의 두 캐릭터 STARTED와 SITE_DESKTOP_READY를 확인한다.
- 제품 동작의 무인 검증 결과는 run-006/007/008이며, 이 실행은 수정본을 직접 사용할 수 있도록 남긴 미리보기다.
