# PLAN-009 SCP-999 조명 샘플의 Godot 검증

2026-11-23 사용자 요청으로 시험 실행을 [PLAN-005 단계 A](PLAN-005-scp-999.md)에 통합했다. 아래는 후보 당시 설계이며 별도 실행 대상이 아니다. 증거는 PLAN-005에 기록한다.

## 목표와 범위

- 목표: ART-001 r002의 4프레임 기본색·노멀·반사 맵을 실제 투명 오버레이에서 비교하고 전체 프레임 제작에 사용할 계약을 확정한다.
- 포함: 독립 진단 씬, 고정 광원/낮·밤 조작, 원본 시안/중립색/조명 결과 비교, 반전·창·입력·품질·비용 측정.
- 제외: PLAN-005의 추적/스트레스 기능, 전체 애니메이션 맵 제작, 실제 로컬 시간/태양 위치 시스템, 배포, 렌더러 변경, 장시간 고부하 시험.
- 요청 근거: 2026-11-23 ART-001 수정 요청에서 필요한 엔진 시험을 별도 후보로 구체화했다. 이 PLAN의 실행 승인은 아직 없다.

- 기반: 완료된 [PLAN-002](PLAN-002-development-environment.md)·[PLAN-003](PLAN-003-overlay-validation.md). 실행 시 실제 설치 버전·기존 창 진단 경로를 다시 확인한다.
- 제작: active [ART-001](../../Art/docs/plans/ART-001-scp-999-character.md), [r002 제출](../../Art/assets/characters/Scp999/revisions/r002/README.md), [전달 계약](../../Art/assets/characters/Scp999/handoff.md), [조명 지침](../../Art/docs/agents/lighting.md).

- r002는 사용자 시각 미승인 진단 샘플이다. 정식 제품 적용 승인으로 취급하지 않는다.

### 구현·비교 계약

- 현 프로젝트 Compatibility/OpenGL 렌더러를 유지하고 실제 Godot/.NET 버전을 증거에 기록한다.
- 진단 씬은 64×64 셀·nearest 1배/2배·피벗 (32,56)을 유지한다. r002 계약의 0~3 인덱스는 원본 UI 프레임 1·7·9·12에 대응한다.
- 세 모드: r001 고정 명암 참조 / r002 기본색만 / r002 기본색+CanvasTexture 노멀·스페큘러. 주광원 하나와 주변 밝기부터 비교한다.
- 정상/좌우 반전의 좌·우·위 광원, 고정 낮/밤을 조작하고 동일 설정을 저장해 재현한다. 원본의 반짝임을 동적 반사에 중복 합성하지 않는다.
- normal은 RGB 방향 데이터(X 오른쪽/Y 위/Z 관찰자 방향), alpha는 255다. 실제 엔진 규약을 확인하며 수동 채널 반전을 중복 적용하지 않는다.
- specular는 RGB 동일 회색값(몸체 180, 표정/윤곽/배경 0)의 후보 입력이다. CanvasTexture의 shininess·색·맵 값이 실제로 어떤 반사 폭/밝기를 만드는지 확인하고 채택값을 기록한다. 흰색=반사 강도라는 가정만으로 연결하지 않는다.
- 기본색만 커버리지/반투명을 소유한다. 데이터 맵을 기본색 팔레트로 양자화하거나 표시색 보정하지 않는다. 맵별 임포트·필터·반복·경계 설정을 남긴다.
- 4장 개별 비교와 샘플 순환은 표면 변화 진단용이다. 중간 프레임이 생략된 샘플 순환을 완전한 move 재생 검증으로 보고하지 않는다.
- 초기 접지 그림자는 진단용 단순 도형으로 분리한다. 색/그림자는 앱의 오버레이 내부 표현이며 뒤쪽 실제 데스크톱을 조명하지 않는다.
- 부드러운 조명과 단계화한 표현의 필요성을 비교한다. 기본 기능에서 문제가 확인될 때만 작은 셰이더 대안을 검토하고 차이·비용을 기록한다.
- 두 네이티브 창은 하나의 조명 상태를 공유한다. 실제 로컬 시간 수집 없이 수동 고정 상태로 검증한다.

| 기준 | 방법 | 증거 |

| 후속 제작 계약 확정 | 엔진/맵 파라미터·반전 처리·품질 한계·수정 사항을 ART-001에 전달 | handoff·실행 README |

- 측정안: 같은 해상도/창 수/개체 수/렌더러/동작, 모드별 10초 준비 후 30초 측정 3회. 1개와 2개 창을 각각 비교한다. 유휴 FPS 제한·VSync를 기록한다.
- 제안 예산: 목표 60Hz에서 p95 프레임 시간 16.67ms 이하, 조명 추가 p95 비용 1ms 이하. CPU/GPU·메모리의 허용 증가량은 실행 초기에 무조명 기준과 수집 가능성을 확인해 측정 전에 수치로 정한다. 현재는 실측값이 아니다.
- 프레임 시간·CPU/GPU·메모리를 수집한다. 수집 불가능한 필수 지표는 미측정으로 기록하고 검증 한계 해결 전 전체 통과로 판정하지 않는다.
- 예산 초과 시 추가 반사/셰이더 단순화→광원/그림자 단순화 순으로 재비교한다. 품질과 비용의 채택 근거 없이 전체 맵 제작을 허용하지 않는다.
- 시험 구현 완료와 샘플 합격은 구분한다. 불합격이면 수정 항목과 재시험 조건을 남기며 ART 전체 제작 게이트는 닫힌 상태다.

## 현재 상황과 다음 행동

- 다음: PLAN-005에서 4장 검증→idle/move 전체 재생 검증. 이 문서를 별도 활성화하지 않는다.
