# 아이콘 좀비의 발·치료 효과 연결 계약

2026-11-25 사용자 요청: ART-006을 발만 있는 보행으로 변경하고, 추가 애니메이션 개발 조건과 ART-007을 보완한다.
기준은 [아이콘 복제 기획](desktop-icon-clones.md), 제작은 [ART-006](../../Art/docs/plans/ART-006-scp-049-2-zombie.md)·[ART-007](../../Art/docs/plans/ART-007-scp-049-mutation.md)이다.
아래는 **제품 통합 계약**이다. PLAN-014에서 기술 통합·보행/깜빡임 수정과 LG 사용자 제품 시각 승인을 완료했다. 2026-11-25 ART-006/007 r001 제작·사용자 시각 승인을 완료했다. 확정 픽셀 간격·태그 길이는 [발 명세](../../Art/assets/characters/Scp0492/spec.md)와 [효과 명세](../../Art/assets/vfx/Scp049Mutation/spec.md), 추가 개발 항목은 각 handoff에 기록한다.

## 현재 구현과 변경 범위

- 현재 아이콘 창은64×64, 취득 그림은 최대48×48이며 가로 중앙·이미지 아래끝y=56으로 배치한다. PLAN-014에서 좀비의 임시 손/발과 원호를 승인 ART-006 발·ART-007 장식 효과로 교체했다.
- 후속 ART-006은 **발 두 개만** 제작한다. 손·팔·얼굴·표정·별도 좀비 몸체는 제외한다. 임시 손 사각형과 해당 입력 영역도 정식 통합 때 함께 제거한다.
- 아이콘의 그림·색·알파·종횡비를 보존한다. 몸체 로고를 반전·회전·찌그러뜨리거나 아트 시트에 굽지 않는다. 보행은 발 교대로 표현하고 몸체 바운스는 최초 범위에서 제외한다.

## ART-006 발 부착과 출력

- 발별32×32 투명 셀, 부착 뿌리(16,28), nearest2배를 기준으로 한다. 같은 시간축의 좌/우 발 PNG 시트와 공통 계약을 전달한다. 좌우는 화면의 왼쪽/오른쪽 슬롯이며 생물학적 좌우가 아니다.
- 한 발의 기본 그림은 뿌리 아래 원본4px 높이 내에 둔다. 전체 제품 합성 영역64×64 안에서 표시상y=56~63의8px를 사용한다. 폭·최대 뻗음은 대표 샘플로 정하며 셀 전체를 발 크기로 해석하지 않는다.
- 개발은 아이콘 알파가0보다 큰 픽셀의 경계를 한 번 계산해 캐시한다. 좀비 상태에서는 그 경계의 가로 중심을x=32에 가장 가까운 정수 위치, 아래끝을y=56에 맞춰 정수 이동만 한다. 투명 여백 때문에 발이 몸체와 떨어지지 않게 하며 원본 이미지를 재표본화하지 않는다.
- 두 발의 뿌리는 보이는 몸체의 하단 중심 좌우에 둔다. 몸체 너비에 따른 간격과 최소/최대 간격, 비대칭·매우 좁은 형태의 보정은 샘플 계약에 수치로 고정한다. 움푹한 모양에서도 연결되어 보이는지를 확인한다.
- 기본 합성 순서는 발 → 아이콘 몸체다. 뿌리의 작은 겹침만 허용하고 로고 중앙을 가리는 앞쪽 부착물은 만들지 않는다. 방향에 따라 발 그림/보행 순서만 전환하며 아이콘은 반전하지 않는다.
- 전달 후보 파일은 `Scp0492_left-foot.png`, `Scp0492_right-foot.png`, `Scp0492.contract.json`. 계약은 동일한 프레임/태그/시간, 각 파일·뿌리·최대 알파 경계·방향 매핑을 명시한다.
- 입력은 현재 기준인 알파16 이상의 아이콘 픽셀과 실제 발 픽셀의 합집합이다. 발 셀 전체·발 사이·임시 손 자리·오라에는 입력 영역을 두지 않는다.

## 게임 전환과 애니메이션 소유

| 사건 | ART-006 | ART-007 | 개발 책임 |
| --- | --- | --- | --- |
| 일반 복제본 | 발 없음 | 없음 | 기존 원본 이미지 유지 |
| 실제 치료 시작 | 발 없음 | treat 반복 시작 | 예약만으로 시작하지 않고 Treating 상태를 따른다 |
| 치료 성공 | spawn 일회 → 현재 이동/대기 | transform 일회 | 같은 성공 사건에서 좀비 전환·발 등장·효과0초 시작 |
| 이동/정지/공중/착지 | move/idle/fall/land | 진행 중인 transform만 유지 | 게임 물리에 맞춰 전환, 프레임이 이동을 결정하지 않음 |
| 치료 취소·대상 회수/소실 | 현재 유효 상태, 성공 spawn 없음 | treat 즉시 제거 | 타이머만으로 성공 효과를 예약하지 않음 |
| 좀비 회수·수명 종료 | collect/expire 일회 | 진행 중 효과 제거 | 논리 삭제와 비상호작용 소멸 표현 분리 |
| 봉쇄·복귀 | 숨김/시간 정지 → 같은 나이 복귀 | 숨김/시간 정지 → 유효 대상에만 복귀 | 봉쇄 시간 따라잡기 금지 |
| 앱 종료 | 즉시 정리 | 즉시 정리 | 소멸 재생을 기다리지 않고 자원 해제 |

- spawn/land는 낙하·드래그·회수 등 더 높은 우선순위의 상태에 즉시 양보한다. 이동 중 spawn은 게임 이동을 멈추지 않는다. 방향 전환으로 매번 태그 시간을0으로 만들지 않는다.
- PLAN-014의 표시 전용 소멸 소유자는 회수/만료를 한 번만 처리하고 대상·예약·입력·생존 수 계산에서 즉시 제외한 뒤, 마지막 이미지/발 자세/위치를 가진 표시 전용 객체를 생성해야 한다.
- 소멸 객체는 아이콘 스냅샷을 읽기 전용으로 보유하고 완전 클릭 투과로 짧게 재생한다. collect/expire의 길이·마지막 완전 투명 프레임과 아이콘 전체 fade 곡선은 제출 계약에 둔다. 아트에 구운 발 알파와 엔진 fade를 중복 적용하지 않는다.
- 게임 객체 제거 후에도 소멸 표현이 쓰는 아이콘 텍스처는 마지막 프레임까지 참조를 유지한다. 종료·봉쇄·반복 회수·대상 소실에서 한 번만 정리하며 보상/회수 횟수/좀비 수명에 재접속하지 않는다.

## ART-007 크기·부착·시간

- 48×48 셀/피벗(24,40), nearest2배로96×96 장식 창을 사용한다. 기존64×64 아이콘 창 안에 잘라 넣지 않는다. 위치는 대상의 공통 표시 기준점에서(48,80)을 뺀 값이며 좀비 transform 기준점은 물리 foot이다. 일반 데이터 treat는 기존 몸체 아래끝과 발바닥 기준의8px 차이를 보정해 foot+(0,8)을 사용한다. 좀비64px 창의 원점은 foot-(32,64), 일반 데이터는 foot-(32,56)이다.
- 한 PNG 시트로 대상보다 앞에 합성하되 로고 중심은 투명하게 비워 주변의 가는 오라·작은 입자를 사용한다. 불투명한 전체 덮개·화면 섬광·새 도구 그림은 제외한다.
- treat는 실제 치료 구간에 반복한다. 현재 논리 치료량은3초, 과부하1.5배 진행 시 실제 약2초다. 효과의 반복 프레임 시간은 유지하고 종료는 게임 상태가 결정한다. 고정3초 영상이나 별도 완료 타이머를 만들지 않는다.
- transform은 현재 MutationSeconds와 같은800ms 일회다. 마지막 완전 투명 프레임의 유지 시간을 포함해 총800ms로 맞추고, 성공 즉시 발이 생기며 효과 끝까지 좀비 전환을 지연하지 않는다.
- 효과는 대상의 이동·발판·드래그 위치를 따라가며 049 본체의 도구 접점에는 붙이지 않는다. 정식 ART-004 본체에는 이미 도구 동작이 있다.
- 96×96 내부에서 의도한 효과가 잘리지 않게 한다. 작업 영역 밖으로 나가는 픽셀은 표시 경계에서 가려 작업 표시줄/인접 모니터를 침범하지 않게 하며, 가장자리에서 효과를 보이게 하려고 대상이나 클릭 좌표를 옮기지 않는다. 이 화면 경계 잘림과 작은 창 때문에 생기는 잘림은 검수에서 구분한다.
- 해당 효과 창 전체를 cross-process 클릭 투과로 만들고 공통 창 순서 관리자를 사용한다. 별도 독립 반복 최상단 요청은 추가하지 않는다.
- 대상 삭제·수명 만료·회수 시 효과를 즉시 정리한다. 재치료는 새 treat0초부터 시작한다. 봉쇄 시 살아 있는 효과만 시간을 보존하며 종료 시 전부 정리한다.
- 파일 후보는 `Scp049Mutation.png`, `Scp049Mutation.contract.json`. Unshaded/Mix/중립 부모, 원본 straight RGBA의 알파를 유지하며 추가 fade를 곱하지 않는다.

## 통합 개발·검증

- [PLAN-014](../plans/PLAN-014-zombie-art-integration.md)에서 발 부착 계산·두 시트 합성·알파 입력, 표시 전용 소멸 상태/캐시 참조,96×96 효과 창·공통 창 순서·동일 게임 시간 연결을 범위로 명시한다. ART 완료만으로 구현됐다고 기록하지 않는다.
- 테스트 소유 원형/사각/비대칭/투명 구멍/큰 여백/좁은 아이콘에 대해 발 연결·원본 식별·부착 좌표·64px/96px 경계·양방향·8개 겹침을 확인한다.
- 치료 정상/과부하/취소/즉시 재시작, 변이 중 이동·회수, 소멸 중 반복 클릭·새 스폰·봉쇄/복귀·앱 종료를 검사한다. 표시만 남은 객체는 실제 외부 수신기로 클릭 투과를 검증한다.
- 같은 창 수·효과 수에서 짧은 비용·자원 정리를 기록하고 미측정 범위는 분리한다. 실제 사용자 아이콘을 제작 원본이나 저장소 증거로 저장하지 않는다.
