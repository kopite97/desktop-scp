# 시스템 반응과 봉쇄 프로토타입

원본: [기획 4·5절](../../SCP_site-desktop.md). 구현/검증: [PLAN-008](../plans/PLAN-008-system-options.md).
아래 수치는 해당 PLAN의 기능 검증용 조정값이며 최종 밸런스 확정이 아니다.

## 트레이 상주와 제어창

- 2026-11-25 사용자 요청에 따른 [PLAN-015](../plans/PLAN-015-tray-residency.md): 실행하면 제어창 없이 트레이에 상주하고 SCP·복제 아이콘은 계속 활동한다.
- 트레이 좌클릭 또는 Show controls로 같은 세션의 제어창을 연다. X·Alt+F4·Hide controls는 제어창만 숨기며 게임 시간·입력 감시·봉쇄 상태를 바꾸지 않는다.
- 정상 트레이 사용 중 완전 종료는 트레이 Exit로 수행한다. 트레이 생성 실패 시 제어창과 Exit 버튼을 유지하며 X로 접근 경로를 숨기지 않는다.
- 트레이의 숨겨진 아이콘 영역/시계 옆 배치는 Windows 사용자 설정을 따른다. 로그인 자동 실행과 Windows 서비스는 구현 범위가 아니다.

## 지표와 반응

- 기본 출력 장치의 마스터 볼륨 **설정값**(0~100%)을 읽는다. 실제 재생 음량·데시벨·오디오 내용은 수집하지 않는다. 음소거는 소음 반응을 끈다.
- CPU는 전체 논리 프로세서의 시스템 시간 차이로 계산한 사용률, RAM은 시스템 물리 메모리 사용률이다. 1초 주기로 읽고 동시에 하나의 수집만 실행한다. CPU 첫 표본은 간격 계산 전이므로 unavailable이다.
- CPU 80% 또는 RAM 85% 이상이면 열기 상태. CPU 70% 미만이며 RAM 75% 미만이면 해제한다. 별도 평균 필터 없이 이력 임계값으로 경계 깜빡임을 줄인다.
- 열기: 구석의 작은 스파크, SCP-999 세로 75%/이동 60%, SCP-049 이동·치료 진행 150%. 바닥 접점과 클릭 윤곽을 함께 맞춘다. 중력과 점프 궤적은 변하지 않는다.
- 음량 70% 이상이면 소음 상태, 65% 미만에서 해제한다. SCP-173 스트레스 +3/초와 임시 불안 표현을 적용한다.
- 5초 넘게 새 표본이 없거나 값이 유효하지 않으면 해당 반응을 해제한다. 볼륨/부하를 실제로 올리지 않고 모의 지표로 경계를 검증한다.

## 강한 연출

- 세션 시작마다 OFF. 사용자가 컨트롤의 강한 연출 옵션을 켜야 한다.
- SCP-173 또는 SCP-049 스트레스 80 이상일 때 현재 전경의 일반 창을 선택한다. 자기 앱·최대화·최소화·메뉴/이동 중·제목 테두리 없는 창은 제외한다.
- ±6px 좌우 이동을 최대1.2초, 시작 간격20초로 제한한다. 활성화·크기·창 순서는 변경하지 않는다.
- 매 이동 전에 옵션·봉쇄·창/PID/스레드·실제 위치를 재검사한다. OFF·봉쇄·포커스 변경·정상 종료 시 마지막 적용 위치가 그대로일 때만 원위치로 돌린다.
- 사용자가 이동/리사이즈했거나 창이 사라지면 효과를 취소하고 그 위치를 덮어쓰지 않는다. 이 경우 원위치 강제 복원도 하지 않는다.

## 봉쇄와 복귀

- UI 버튼, 트레이 우클릭 메뉴, Ctrl+Shift+L이 같은 명령을 사용한다. 단축키 충돌 시 컨트롤에 unavailable을 표시하고 UI·트레이를 유지한다.
- 명령을 받으면 먼저 모든 SCP·복제 아이콘·입력 감시·게임 시간·새 아이콘 취득 반영을 멈추고 외부 효과를 취소한다. 선택 작업 영역 상단 중앙에는 잠금 아이콘·LOCKDOWN·“SCP 활동 일시 정지”·재개 방법의 440×112 배너를 1.5초 표시한다. 0.12초 등장·마지막0.3초 퇴장으로 처리하며 짧은 낮은 경보는 유지한다.
- 2026-11-25 사용자 피드백에 따라 화면 오류처럼 보이던 전체 화면 가로줄 셔터를 제거했다. 배너는 기존 네이티브 클릭 투과 경로를 사용하며 게임 중단을 연출 종료까지 지연하지 않는다. 빠르게 재개하면 배너·경보도 즉시 끝낸다.
- 컨트롤 창은 트레이로 숨긴다. 트레이 생성 실패 시 컨트롤 창을 남겨 복귀 경로를 유지한다. 트레이의 Show controls는 봉쇄 상태를 유지한 채 버튼을 다시 표시한다.
- 해제 시 위치·객체·스트레스·치료 진행을 보존한다. 봉쇄 중 경과 시간은 따라잡지 않는다. 입력 드래그/시선 미관찰 타이머는 안전하게 초기화하고 새 지표·아이콘 결과만 반영한다.
- 해제만으로 제어창을 열지 않는다. 봉쇄 중 명시적으로 연 제어창은 유지한다. 제어창 표시와 게임 봉쇄는 독립적인 상태다.
- 봉쇄 상태와 강한 연출 옵션은 디스크에 저장하지 않는다. 새 실행은 활동 상태·강한 연출 OFF로 시작한다.
- 봉쇄 배너·스파크·불안 모션은 코드 기반 표현이다. 정식 캐릭터·효과 아트 승인을 의미하지 않는다.

## SCP별 활성화와의 관계

[PLAN-016의 활성화 규칙](scp-activation.md)에 따라 재개 시 사용자 ON인 SCP만 활동한다. 비활성 SCP는 지표 반응·스트레스 완화/누적·외부 효과에서 제외하며 모두 OFF여도 트레이 접근은 유지한다. 일반 아이콘과 049 소유 좀비의 활동 조건은 해당 규칙을 따른다.
