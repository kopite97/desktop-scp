# SCP별 활성화

2026-11-25 사용자 [PLAN-016](../plans/PLAN-016-scp-activation.md) 실행 승인에 따른 제품 규칙이다.

- 제어창의 SCP 활성화 목록에서 999·049·173을 각각 켜고 끈다. 기본값은 모두 ON이며 표시 설명과 목록은 SCP 등록 정보에서 생성한다.
- 체크는 사용자 선택이다. 실제 상태는 활성·봉쇄 중·비활성이며, ON이라도 전체 봉쇄 중에는 활동하지 않는다. 봉쇄 중 선택을 바꾸면 재개 시 최종 선택만 적용한다.
- 제어창 숨김과 SCP 활동은 독립적이다. 모두 OFF여도 트레이·제어창·종료 경로는 유지한다.
- 개별 OFF는 본체·소유 효과를 숨기고 AI·물리·입력·시간·스트레스 증감·지표 반응을 중단한다. 외부 창 효과의 요청 자격을 잃고 해당 소유자가 시작한 효과도 취소한다.
- 위치·스트레스·생존 개체는 같은 세션에 보존한다. 드래그·예약·치료/공격은 취소하며 재개 시 최신 환경에서 다시 탐색한다. 비활성 시간을 따라잡지 않는다.
- 전체 봉쇄만 하면 기존 치료 진행·예약을 보존한다. 봉쇄 중 개별 OFF를 선택하면 그 SCP에는 취소 규칙을 적용한다.
- 일반 복제 아이콘은 실제 활동 중인 049 또는 173이 있으면 계속 생성·갱신된다. 049가 없어도 173은 공용 아이콘을 파손할 수 있다. 소비자가 없으면 공용 표시·시간·아이콘 취득을 정지한다.
- 기존 좀비는 049에 종속한다. 049 OFF이면 숨김·수명 정지, 다시 ON이면 남은 수명으로 돌아온다. 치료/변이 오라와 소멸 잔상은 개별 OFF에서 정리한다. 049-2 독립 설정은 이번 범위에 없다.
- ON/OFF만 `user://scp-settings.json`의 안정된 ID로 저장한다. 시작 시 개체 표시 전에 읽는다. 위치·스트레스·개체·봉쇄·강한 연출은 저장하지 않는다.
- 저장되지 않은 신규 SCP는 등록 기본값을 따른다. 잘못된 개별 값은 기본값을 쓰고 알 수 없는 ID는 실행하지 않는다.
- 손상/상위 버전 원본은 보존한다. 이후 선택은 `.recovered.json`에 저장하며 다음 실행에서 원본을 읽을 수 없으면 복구 파일을 사용한다. 읽기/저장 오류는 제어창에 안내하고 세션 선택을 유지한다.
- 강한 연출은 매 실행 OFF이며 [시스템 반응](system-reactions.md)의 대상·취소·복원 규칙을 유지한다.
