# 실제 바탕화면 아이콘의 게임 복제본

2026-11-25 사용자 요청으로 채택한 제품 방향이다. [기획 원본](../../SCP_site-desktop.md)의 고정 .tmp/쓰레기 그림을 이 규칙으로 대체한다. 구현·검증 상태는 [PLAN-012](../plans/PLAN-012-desktop-icon-clones.md)를 따른다.

## 외형과 대상

- Windows 바탕화면의 바로가기·폴더·파일 등 항목에서 런타임에 얻은 아이콘 이미지를 게임 오브젝트의 기본 외형으로 사용한다. Chrome 로고나 Windows 폴더를 미리 그려 배포하지 않는다.
- 일반 상태에서는 취득 이미지의 형태·색·알파·종횡비를 유지한다. 32×32 도트로 다시 그리거나 1px 윤곽·색 보정을 원본 이미지에 굽지 않는다. SCP 캐릭터와 추가 효과에는 기존 도트 스타일을 적용한다.
- 최초 범위는 아이콘 그림이다. 파일명 라벨·선택 배경·마우스 오버 강조와 바탕화면 전체 픽셀 복제는 포함하지 않는다. 바로가기 화살표·동기화 배지·사용자 지정 아이콘의 재현 수준은 실제 비교로 구분하고 지원 한계를 기록한다.
- 일반 폴더·바로가기뿐 아니라 썸네일로 보이는 항목도 있을 수 있다. 최초 구현은 파일 내용 썸네일 대신 아이콘 취득을 사용하며, 해당 항목을 화면과 동일하다고 보고하지 않는다. 일치시킬 수 없는 유형은 제외하거나 제한 유형으로 명시한다.

## 생성과 상호작용

- 취득한 이미지로 독립된 메모리상의 게임 객체를 만들고 기존 스폰 위치·수명·상한 정책을 사용한다. 원래 아이콘 위치를 추적하거나 원본을 가려 움직인 것처럼 만드는 연출은 이번 범위에 포함하지 않는다.
- 실제 아이콘은 그대로 남는다. 게임 복제본 클릭은 기존 회수 동작이며 파일 열기·바로가기 실행으로 연결하지 않는다.
- SCP-049가 복제본을 예약·치료한다. 좀비로 변해도 같은 아이콘 이미지를 몸체로 유지하고 발 두 개와 공통 치료/변이 오라를 합성한다. 손·팔·얼굴·표정은 추가하지 않는다. 좌우 이동 때 로고 자체를 거울 반전하지 않고 부착 요소·동작 방향을 전환한다.
- SCP-173은 같은 게임 객체의 이미지에 접힘·파손을 적용한다. 실제 Windows 항목에는 영향을 주지 않는다.
- 아이콘 취득 실패·빈 목록이면 새 스폰을 건너뛰고 재시도한다. 별도 고정 파일 그림 제작을 요구하지 않는다. 이미 생성된 복제본은 이미지 스냅샷으로 기존 수명을 마친다.

## 환경 관찰과 수명

- 바탕화면 최상위 항목과 아이콘 취득에 필요한 Shell 메타데이터·아이콘 리소스만 읽는다. 디렉터리 재귀 탐색·원본 파일 내용 처리·앱 실행·원본 이동/삭제/숨김은 하지 않는다.
- 사용자/공용 및 리디렉션된 Desktop을 단순 경로 문자열로 가정하지 않는다. 실제 Desktop 뷰와 Shell 결과의 대응을 검증한다. 숨긴 항목·화면에 없는 가상 항목의 후보 포함 여부도 이 경계에서 다룬다.
- 런타임 이미지·식별 정보는 세션 메모리에서 관리한다. 사용자 아이콘·경로·파일명을 Art 에셋이나 저장소 증거로 자동 수집하지 않는다. 검증 증거는 테스트 소유 항목을 사용한다.
- 새 카탈로그 관찰은 이후 스폰에 반영한다. 원본 변경/삭제로 살아 있는 복제본의 이미지가 갑자기 바뀌지 않게 한다. 봉쇄 중 새 스폰을 멈추고 종료 시 취득 작업·캐시·네이티브 자원을 정리한다.

## 발·효과의 후속 연결

2026-11-25 사용자 수정 요청에 따른 [발·치료 효과 연결 계약](icon-zombie-presentation.md)을 따른다. 발 부착·소멸 표현 수명·별도 효과 창은 후속 통합 사항이며 현재 임시 손/발 도형을 변경한 상태는 아니다.
