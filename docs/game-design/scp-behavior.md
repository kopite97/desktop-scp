# SCP 행동과 이동 복구

기준: [기획 원본](../../SCP_site-desktop.md), [활성화](scp-activation.md), [PLAN-017](../plans/PLAN-017-shared-behavior-and-decoupling.md).
2026-11-25 PLAN-017 실행 승인 범위다. 구현/검증 완료 여부는 PLAN에서 관리한다.

- 049는 도달 가능한 치료 대상을 선택한다. 이동 실패 시 예약을 해제하고 제한된 횟수만 재시도한다. 대안이 없으면 기다리며 환경/대상 변화 뒤 다시 탐색한다. 같은 모니터 내 실패 복구 목적으로 순간이동하지 않는다. 모니터 간 이동은 아래 포털 계약을 따른다.
- 999는 커서가 멀어도 대기와 배회를 반복한다. 가까운 커서는 도달 가능한 발판상의 목적지로 투영한다. 추적 시작/해제 거리를 달리하여 경계에서 반복 전환하지 않는다. 공간이 없으면 안정적으로 대기한다.
- 쓰다듬기·드래그와 낙하/착지는 자율 이동보다 우선한다. 타이핑 반응·점액·치료·변이·관찰/공격·좀비 코너 배회의 기존 역할은 유지한다.
- 화면 끝에서 움직이지 않으면 보행 표현/점액도 실제 운동 결과를 따른다. 움직이는 창에 실려 이동한 것은 자기 보행으로 계산하지 않는다.
- 개별 OFF는 행동·예약·일시 효과를 취소한다. 전체 봉쇄는 기존 계약에 따라 시간을 정지하고 복귀 시 환경/대상을 재검사한다. 중단 시간을 따라잡지 않는다.

초기 조정값: 999 대기1~3초, 배회80~220px, 추적 시작420px/해제520px, 정체1.5초, 일반 이동12초, 좀비 장거리 이동60초, 049 탐색0.2초/실패 최대3회. 구현 검증에 따라 조정할 수 있는 프로토타입 값이며 확정 밸런스로 취급하지 않는다.

## 모니터 간 포털 이동

2026-11-26 [PLAN-018](../plans/PLAN-018-monitor-portals-and-local-spawning.md) 실행 승인으로 채택했다. 최초 적용은049이며 999/173/좀비 정책은 유지한다.

- 현재 화면의 도달 가능한 대상이 우선이다. 없으면 출발 바닥과 목적 화면의 바닥→목표 경로가 모두 가능한 원격 대상을 예약한다.
- 출발 지점까지 보행→포털 소멸→위치 한 번 확정→도착 출현→목표 보행. 연출1초(0.4/0.2/0.4초), 작은 타원/입자이며 전체 화면 셔터·섬광·소리는 없다.
- 우클릭 드래그는 출발 준비보다 우선하며 기존 예약을 취소한다. 다른 화면에 드롭 후 착지부터 원격 탐색5초 유예, 로컬 목표는 처리 가능하다. 전이 완료 후 원격 재이동도5초 대기한다.
- 연출 중에는 몸을 다시 드래그하지 못하고 본체/효과는 클릭을 통과시킨다. 봉쇄는 시계·예약을 보존하고 화면을 숨긴다. OFF/종료는 취소·정리한다.
- 목표 소실/화면 무효화 시 취소한다. 위치 확정 전에는 출발, 이후에는 도착 위치를 유지하며 모니터 제거 시 남은 작업 영역으로 복구한다.
- 장거리 정상 이동은 구간 거리 기반 시간 예산을 사용한다. 진전 없는 정체 감지와 전체 시도 상한을 따로 두며 제한을 계속 초기화하지 않는다.
